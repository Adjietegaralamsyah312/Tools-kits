JWT Decoder

Decode JWT untuk membaca header dan payload-nya. 100% di sisi klien — tidak ada yang diunggah atau disimpan.

⚠️ Decoding bukan verifikasi. Siapa pun dapat membaca payload JWT. Selalu verifikasi signature di sisi server dengan secret atau public key.
Header akan muncul di sini.
Payload akan muncul di sini.
Info signature akan muncul di sini.

Cara menggunakan

  1. Tempel JWT (header.payload.signature).
  2. Klik Decode.
  3. Baca header dan payload; periksa catatan signature.

FAQ

Apakah token saya diunggah?

Tidak. Decoding berjalan secara lokal di browser Anda dan token tidak pernah disimpan atau dikirim ke mana pun.

Apakah decoding memverifikasi signature?

Tidak. Decoding hanya membaca token. Verifikasi signature di sisi server dengan secret atau public key.
