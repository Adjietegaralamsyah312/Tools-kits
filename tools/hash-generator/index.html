Hash Generator

MD5, SHA-1, SHA-256, SHA-512. Menggunakan Web Crypto API bila didukung.

⚠️ Hashing bukan enkripsi. Hash bersifat satu arah dan tidak dapat didekripsi. Jangan pernah gunakan MD5/SHA-1 untuk kata sandi — gunakan bcrypt/argon2 di sisi server.
MD5— SHA-1— SHA-256— SHA-512—

Apa itu hashing?

Hash memetakan input menjadi sidik jari berukuran tetap. Digunakan untuk checksum dan integritas, bukan kerahasiaan.
