Hash Generator

MD5, SHA-1, SHA-256, SHA-512. Uses Web Crypto API when supported.

⚠️ Hashing is not encryption. Hashes are one-way and cannot be decrypted. Never use MD5/SHA-1 for passwords — use bcrypt/argon2 server-side.

What is hashing?

A hash maps input to a fixed-size fingerprint. Used for checksums and integrity, not secrecy.
