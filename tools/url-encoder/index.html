URL Encoder / Decoder

Encode and decode URLs and query strings.

Result will appear here.

What is URL encoding?

URL encoding (percent-encoding) converts reserved characters like spaces to %20 so URLs stay valid.

How to use

  1. Paste URL or text.
  2. Choose Component for query values, Full URL to keep ://?&=.
  3. Click Encode/Decode.

FAQ

encodeURI vs encodeURIComponent?

encodeURI keeps URL structure; encodeURIComponent encodes everything including slashes — use it for single parameter values.
