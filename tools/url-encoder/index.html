URL Encoder / Decoder

Encode dan decode URL serta query string.

Hasil akan muncul di sini.

Apa itu URL encoding?

URL encoding (percent-encoding) mengubah karakter khusus seperti spasi menjadi %20 agar URL tetap valid.

Cara menggunakan

  1. Tempel URL atau teks.
  2. Pilih Komponen untuk nilai query, URL Penuh untuk mempertahankan ://?&=.
  3. Klik Encode/Decode.

FAQ

encodeURI vs encodeURIComponent?

encodeURI mempertahankan struktur URL; encodeURIComponent meng-encode semuanya termasuk garis miring — gunakan untuk nilai parameter tunggal.
