What is Base64?

Base64 encodes binary data as ASCII text, commonly used for data URIs, tokens and email attachments. It is not encryption.

How to use

  1. Paste text.
  2. Click Encode or Decode.
  3. Copy or download.

FAQ

Does it support Unicode/emoji?

Yes, via UTF-8 TextEncoder/TextDecoder.

Is Base64 secure?

No. Anyone can decode it. Never use it for passwords.
