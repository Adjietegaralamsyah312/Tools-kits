Cara menggunakan

FAQ

Apakah teks saya diunggah?

Tidak. Perbandingan berjalan secara lokal di browser Anda.

Seberapa besar input yang bisa dipakai?

Hingga 500 baris atau sekitar 100.000 karakter per sisi agar browser tetap responsif.
