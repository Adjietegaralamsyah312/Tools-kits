Safety note

Very complex patterns (e.g. nested (a+)+) can freeze any browser. This tool validates syntax, limits pattern to 500 chars and text to ~50k chars, runs matching in a Web Worker with a 1.5s timeout (stopped automatically), and caps matches at 500.
