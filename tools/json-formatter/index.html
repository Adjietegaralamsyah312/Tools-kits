Apa itu JSON Formatter?

JSON formatter mempercantik JSON yang ringkas atau berantakan dengan indentasi yang konsisten sehingga Anda dapat membaca dan men-debug respons API dengan cepat. Alat ini berjalan 100% di browser Anda — tidak ada yang diunggah.

Cara menggunakan

  1. Tempel JSON.
  2. Klik Formatkan.
  3. Periksa hasilnya.
  4. Salin atau unduh.

Contoh

Input: {"a":1,"b":[2,3]} → diformat dengan indentasi 2 spasi.

FAQ

Apakah JSON saya dikirim ke server?

Tidak. Semua pemrosesan menggunakan JSON.parse secara lokal.

Bagaimana cara memperbaiki JSON yang tidak valid?

Periksa baris/kolom pada pesan error. Masalah umum: tanda kutip hilang, koma berlebih, tanda kutip tunggal.

Bisakah saya mem-minify JSON?

Ya, klik Minify atau kunjungi JSON Minifier kami.
