JSON Validator

Validasi JSON dan dapatkan pesan error yang jelas dan ramah dengan petunjuk baris.

Hasil validasi akan muncul di sini.

Apa itu validasi JSON?

Validasi memeriksa apakah teks Anda mengikuti spesifikasi JSON (RFC 8259). JSON yang tidak valid merusak API dan konfigurasi.

Cara menggunakan

  1. Tempel JSON.
  2. Klik Validasi.
  3. Perbaiki baris yang ditandai jika tidak valid.

FAQ

Apa saja error JSON yang umum?

Koma berlebih, tanda kutip tunggal, kunci tanpa kutip, komentar.

Apakah data diunggah?

Tidak, validasi berjalan secara lokal.
