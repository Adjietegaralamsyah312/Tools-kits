Tentang Tools Kits

Tools Kits adalah kumpulan alat online gratis yang dibangun dengan satu prinsip: cepat, sederhana, ramah privasi. Tanpa akun, tanpa paywall, tanpa unggahan untuk alat yang dapat berjalan di browser Anda.

Prinsip

  • Utamakan client-side (JSON, gambar, teks tidak pernah meninggalkan perangkat Anda)
  • Dependensi minimal, halaman cepat
  • Aksesibel & mobile-first
  • Ramah SEO dengan konten unik per alat

Teknologi

HTML + CSS statis + JavaScript vanilla. Tanpa langkah build, dapat di-deploy ke GitHub Pages. Satu registri (assets/js/tools-data.js) mendukung pencarian dan daftar.
