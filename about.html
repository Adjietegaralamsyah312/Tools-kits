About Tools Kits

Tools Kits is a collection of free online tools built on one principle: fast, simple, privacy-friendly. No accounts, no paywalls, no uploads for tools that can run in your browser.

Principles

  • Client-side first (JSON, images, text never leave your device)
  • Minimal dependencies, fast pages
  • Accessible & mobile-first
  • SEO-friendly with unique content per tool

Stack

Static HTML + CSS + vanilla JavaScript. Zero build step, deployable to GitHub Pages. One registry (assets/js/tools-data.js) powers search and listings.
