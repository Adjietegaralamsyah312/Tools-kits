Kebijakan Privasi

Input alat Anda tidak pernah meninggalkan perangkat Anda. JSON, Base64, gambar, teks, dan file diproses dengan API browser (Canvas, Web Crypto). Kami tidak mengunggah, menyimpan, atau mencatatnya.

  • Tanpa akun, tanpa database input alat
  • Tanpa pelacakan invasif; hook analitik (ToolskitsAnalytics) adalah stub no-op yang dapat Anda sambungkan ke penyedia ramah privasi nanti
  • Preferensi tema hanya disimpan di localStorage browser Anda
  • Nol permintaan pihak ketiga: pustaka QR (qrcode-generator) di-hosting mandiri, semua halaman lain hanya menggunakan aset pihak pertama

Data formulir kontak (saat disambungkan ke backend) harus ditangani sesuai kebijakan penyedia Anda. Jangan kirim rahasia melalui formulir.
